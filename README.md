# 小组件车联 4.0.0

根据群内大佬「飛」的版本进行了少许修改，感谢「飛」的分享与贡献。

支持在 Scripting 中自动识别奥智联 / 奥捷智行授权，提供小、中、大、超大四种尺寸的车辆小组件及车辆中心。

本版基于用户确认通过的试用版 3.14.2（tone 修正版），恢复正式名称“小组件车联”及正式意图标识。按用户要求，目前仅提供本地安装包，尚未发布 GitHub。

## 安装

1. 使用 Scripting 导入“小组件车联-4.0.0.scripting”。正式版同名升级；“试用版”可独立保留。
2. 打开“小组件车联”，在“组件设置 → 授权与地图”自行填写完整 Authorization，保留原有前缀。Token 保存到系统钥匙串。
3. 如需高德地址解析，填写自己的高德 Web 服务 Key；可以留空。
4. 在车辆中心刷新后，在桌面选择“小组件车联”。从试用版切换时，正式版授权独立保存，需在正式版中配置或恢复自己的备份。

## 主要功能

- 四种尺寸独立设置；自定义车图、背景、字号、字体与按钮颜色、透明度和信息卡片内容。
- 支持 1–7 个自定义快捷按钮（含空白），按按钮设置二次确认。
- 支持天气、油价与预测、座椅加热联动及自定义启动 / 冷车 / 热车运行时间。
- 奥捷尾门开 / 关控制；车门、尾门、机盖分别显示状态与提醒。奥捷机盖已通过抓包验证，奥智联机盖仍为未知。
- 车辆中心可单独设置车图，保留奥迪四环 Logo；按钮、确认页与对应状态提醒共用 SVG。
- 车辆中心右上角圆形按钮使用内部字面量填充色，避免 props 动态填充在用户设备上渲染成方块。
- 支持设置、图片及车况 / 天气 / 油价缓存备份恢复。
- 油耗：车况页显示平均油耗与预计续航，样本累计不足时回落到小熊油耗车系加权参考值，并在设置「油耗参考」里可见来源与车主样本数。

详细区别见 [CHANGELOG](CHANGELOG.md)，对比基准为用户于 2026-10-26 提供、元数据为 3.9.9 的包。

## 隐私与备份

脚本不内置个人 Token 或高德密钥，安装包不包含账号配置、车况缓存或 HAR。用户主动导出的备份可能含 Token、高德 Key 和缓存，请自行保管。
